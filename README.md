# MNIST CNN：训练、验证与推理

## 项目介绍

输入为经过预处理的 28×28 灰度手写数字图片，输出为数字 0～9 的预测类别。

项目基于 [PyTorch 官方 MNIST 示例](https://github.com/pytorch/examples/tree/main/mnist) 学习与改造。

目前已实现数据预处理、训练集与验证集划分、CNN 训练、
模型评估、按验证损失保存最佳权重、权重加载、
单张图片预测及独立测试集评估。

### 我的改进

1. **增加验证集划分**：在原始 MNIST 训练数据中划分训练集和验证集，实现训练、验证、测试三阶段的数据管理，避免直接使用测试集进行模型选择。

2. **实现最佳模型权重保存**：增加验证损失监控机制，每轮训练结束后评估模型表现，仅在验证损失创下历史新低时保存模型权重，避免直接使用最后一轮模型作为最终模型。保存条件：启用 --save-model 时，仅在验证损失创下历史新低时保存模型权重。

3. **增加独立测试入口**：编写 evaluate()，按实际样本数累计损失并计算分类准确率；新增 test.py，加载最佳权重，在不重新训练的情况下完成测试集评估。

4. **实现单张图片独立推理**：新增 `predict.py`，支持通过 `--index` 命令行参数选择 MNIST 测试图片，完成模型权重加载、类别预测、真实标签对比和非法索引检查。

5. **重构项目模块结构**：将模型定义、数据预处理、训练、评估和推理逻辑拆分至 `model.py`、`data.py`、`main.py`、`evaluate.py`、 `test.py`和 `predict.py`，降低模块耦合，提高代码复用性与可维护性。

6. **统一训练与推理的数据预处理**：封装 `build_transform()`，统一使用 `ToTensor()` 和 `Normalize()`，保证训练、验证及推理阶段采用一致的数据标准化参数，减少预处理不一致带来的预测偏差。

## 实验结果
训练集包含 54,000 张图片，验证集包含 6,000 张图片。
使用 CPU 训练 2 轮，batch size 为 64，随机种子为 1。
根据最低验证损失选择第 2 轮权重，再通过 test.py 独立评估测试集。

| 数据集 | 样本数 | 平均损失 | 准确率 |
|---|---:|---:|---:|
| 验证集 | 6,000 | 0.0413 | 98.62% |
| 测试集 | 10,000 | 0.03945 | 98.74% |

以上为单次固定划分、固定随机种子下的实验结果，
尚未进行多随机种子重复实验。

## 项目结构

- main.py：训练入口、数据划分、验证与最佳权重保存。
- model.py：CNN 模型结构。
- data.py：训练和推理共用的数据预处理。
- evaluate.py：计算平均损失和分类准确率。
- predict.py：加载最佳权重，预测指定索引的测试图片。
- test.py：加载最佳权重，独立评估完整测试集。
- requirements.txt：直接依赖及版本。
- notes/：实验记录与学习笔记。
- train.py：单轮训练与 dry-run 支持。
- error_analysis.py：收集验证集错误，并统计常见误分类组合。

## 如何运行

在 `pytorch-examples/mnist` 目录中执行以下命令。
### 验证集误分类分析

```bash
python error_analysis.py
```

需要先准备 MNIST 数据和最佳权重 `mnist_cnn_16ch_best.pt`。
脚本使用种子 1，按 54,000 / 6,000 的比例重建训练集与验证集，
加载权重后分析验证集，不重新训练。

原实验最佳权重在 6,000 张验证图片上产生 83 个错误：
其中 9→7 有 10 次，2→7 有 9 次，9→4 有 6 次。

详细记录见 [误分类分析笔记](notes/06_error_analysis.md)。
这些是误分类次数，不代表各类别错误率。

### 环境

本次实验使用：
- Python 3.12.15
- PyTorch 2.14.1
- torchvision 0.29.1
- CPU

在已激活的 Python 3.12 虚拟环境中安装依赖：

```bash
uv pip install -r requirements.txt
```

如果环境中已安装 pip，也可以使用：

```bash
python -m pip install -r requirements.txt
```
### 训练并保存最佳权重

```bash
python main.py --epochs 2 --no-accel --batch-size 64 --save-model
```

首次训练会下载 MNIST 数据。按最低验证损失保存权重至：
`mnist_cnn_16ch_best.pt`。

### 独立测试

```bash
python test.py
```

需要先完成训练，生成最佳权重并下载数据。
该命令加载已有权重，不重新训练。

### 单张图片预测

```bash
python predict.py --index 10
```

`--index` 的合法范围为 `0～9999`。
输出预测类别与真实标签。

模型权重和原始数据不随 Git 仓库提交，需要按上述步骤生成。
